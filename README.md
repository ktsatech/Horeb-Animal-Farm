# Horeb Animal Farm — Official Website

A static HTML, CSS, and JavaScript website for Horeb Animal Farm in Nyakabirizi, Bushenyi District, Uganda.

## Pages
- `index.html` — Home
- `about.html` — Our Legacy & Team (Pr. Peter Musoke, Nayebare Marion, Dr. Ebenezar Mukwano)
- `gallery.html` — Livestock Gallery
- `exclusive.html` — Organic Manure & Farm Training Services
- `contact.html` — Contact & Bookings

## Run Locally
No build step or dependencies required. Serve the folder with any static file server, for example:

```
npx serve .
```

or open `index.html` directly in a browser.

## SEO
Each page includes a unique title, meta description, canonical URL, Open Graph/Twitter card tags, and JSON-LD structured data (`LocalBusiness`, `Person`, `Product`/`Service`). `sitemap.xml` and `robots.txt` are included at the project root.
